# clone-tabnews-ai
Implementação do TabNews para o curso.dev utilizando agentes de IA.

Atualmente, exibe a página Família Dantas com Next.js 16 (Active LTS),
App Router, JavaScript e CSS.

Requer Node.js 20.9 ou superior.

```sh
npm install
npm run dev
```

Abra http://localhost:3000.

Para executar em produção:

```sh
npm run build
npm start
```
